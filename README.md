# helpdesk-ti-mvc

Sistema web para la gestión de tickets de soporte técnico desarrollado con
Angular, Node.js, TypeScript y PostgreSQL.

## Estado del desarrollo

Los pasos 1 al 6 están completados. El frontend Angular y la estructura
inicial del backend Node.js con Express, TypeScript y arquitectura MVC se
encuentran disponibles en el repositorio.

El siguiente paso es configurar PostgreSQL y comprobar la conexión desde el
backend.

## Componentes

- `frontend`: aplicación web desarrollada con Angular.
- `backend`: API REST con Node.js, Express y TypeScript.
- `database`: scripts y documentación del modelo de datos.
- `docs`: requisitos y evidencias del desarrollo.
