# HelpDesk TI - Frontend

Aplicación web desarrollada con Angular, TypeScript, HTML y CSS para consumir
la API REST de HelpDesk TI.

## Tecnologías

- Angular 22
- TypeScript
- HTML y CSS
- Angular Router
- Angular Reactive Forms
- Angular HttpClient
- RxJS
- Vitest

## Funcionalidades

- Inicio y cierre de sesión.
- Recuperación de la sesión.
- Interceptor JWT.
- Guards de autenticación y roles.
- Panel de inicio dinámico por rol.
- Listado, filtros y paginación de tickets.
- Creación y actualización de tickets.
- Asignación de técnicos.
- Cambios de estado y solución.
- Historial de tickets.
- CRUD visual de usuarios.
- CRUD visual de categorías.
- Panel administrativo de métricas.
- Diseño responsive.

## Requisitos

- Node.js instalado.
- npm instalado.
- Backend disponible en `http://localhost:3000`.

## Instalación

```bash
npm install
```
