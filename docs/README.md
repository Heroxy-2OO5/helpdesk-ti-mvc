## Organización del proyecto

- `frontend`: aplicación Angular.
- `backend`: API REST con Node.js y Express.
- `database`: esquema, datos iniciales, vistas y documentación PostgreSQL.
- `docs`: requisitos, avances, pruebas y evidencias.

La documentación del modelo entidad-relación y el diccionario de datos están
disponibles dentro de la carpeta `database`.
